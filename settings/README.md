# Gerador de Token em Python

Um gerador de Token desenvolvido em Python com foco em prática de lógica de programação, manipulação de strings e estruturação de funções.

## Funcionalidades

- Geração de Token aleatórias
- Escolha da quantidade de caracteres
- Opção de incluir caracteres especiais
- Verificação de força da senha
- Sistema de reinício integrado

## Tecnologias Utilizadas

- Python 3
- Biblioteca `random`
- Biblioteca `string`

## Conceitos Praticados

Este projeto foi criado para desenvolver habilidades em:

- Loops (`while` e `for`)
- Condicionais (`if`, `elif`, `else`)
- Funções
- Retorno de valores (`return`)
- Manipulação de strings
- Entrada de dados com `input`
- Validação básica de dados

## Como Executar

Clone o repositório:

```bash
git clone https://github.com/GabrielMarcianoarante/GeradorDeSenha.git
```

Entre na pasta do projeto:

```bash
cd Gerador
```

Execute o arquivo:

```bash
python main.py
```

## Objetivo do Projeto

O objetivo deste projeto é praticar fundamentos importantes da programação em Python através da criação de uma aplicação simples, funcional e útil.
